# Plotto

Plotto is a plot library, 100% Elixir, that's focused on generating beautiful SVG charts and export using the same aspect to PNG when it's needed.

It is very useful when you are developing a website and need to integrate SVG charts and even if you are using LiveView, these SVG charts are helping you adding events, actions, and feedback to be handled via LiveView.

In addition, if you need to export or generate PNG charts for email, PDF, for sending via Telegram, Slack, or even Mattermost, you can use the export to this format and make easy use of both.

## Installation

The package can be installed by adding `plotto` to your list of dependencies in `mix.exs`:

```elixir
def deps do
  [
    {:plotto, "~> 0.1.0"}
  ]
end
```

Enjoy!
